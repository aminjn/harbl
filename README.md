# سامانه اسکرپر HAR

اسکرپر تحت وب برای سایت‌هایی که با آن‌ها قرارداد دارید. فایل HAR را آپلود می‌کنید، سامانه درخواست‌های API داخل آن را (با همان هدرها و کوکی‌ها) دوباره اجرا می‌کند و پاسخ‌ها را به‌صورت JSON ذخیره می‌کند؛ دستی یا زمان‌بندی‌شده.

## نصب روی سرور (آروان یا هر Ubuntu)

```bash
sudo apt-get install -y unzip
unzip har-scraper.zip && cd har-scraper
sudo bash deploy/install.sh              # بدون دامنه
sudo bash deploy/install.sh panel.example.com   # با دامنه و SSL
```

اسکریپت پایتون، Nginx، سرویس systemd و فایروال را نصب و تنظیم می‌کند. اگر به PyPI دسترسی نباشد، پکیج‌ها از `deploy/wheels` نصب می‌شوند. رمز ادمین در `/etc/har-scraper.env` است.

دستورهای مفید:
```bash
systemctl status har-scraper        # وضعیت
journalctl -u har-scraper -f        # لاگ زنده
sudo systemctl restart har-scraper  # بعد از تغییر رمز یا کد
```

## اجرای محلی

```bash
pip install -r requirements.txt
export HARSCRAPER_USER=admin
export HARSCRAPER_PASS='یک-رمز-قوی'
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

سپس `http://localhost:8000` را باز کنید و با نام کاربری/رمز بالا وارد شوید.

## روند کار

1. **سایت جدید**: نام، شماره قرارداد (اجباری)، دامنه‌های مجاز، تاریخ پایان قرارداد، فاصله بین درخواست‌ها و زمان‌بندی را وارد کنید.
2. **گرفتن HAR**: در Chrome، DevTools ← تب Network ← در سایت لاگین کنید و صفحات موردنظر را باز کنید ← راست‌کلیک ← *Save all as HAR with content* (در نسخه‌های جدید: *Export HAR (with sensitive data)*).
   - **مهم:** کروم از نسخه ۱۳۰ به بعد به‌طور پیش‌فرض HAR را «sanitized» ذخیره می‌کند، یعنی کوکی و هدر Authorization حذف می‌شوند و اجراها خطای ۴۰۱/۴۰۳ می‌دهند. ابتدا در DevTools ← ⚙️ Settings ← Preferences ← Network گزینه **Allow to generate HAR with sensitive data** را روشن کنید. پنل اگر HAR بدون کوکی باشد هشدار می‌دهد.
   - راه دیگر: کوکی/توکن را در فیلد «هدرهای اضافه» در تنظیمات سایت وارد کنید (مثلاً `Cookie: sessionid=...`). این هدرها جایگزین هدرهای هم‌نام HAR می‌شوند و وقتی نشست منقضی شد کافی است فقط همین را عوض کنید.
3. **آپلود HAR** در تب «HAR و درخواست‌ها». فقط درخواست‌های XHR/Fetch/JSON روی دامنه‌های مجاز نگه داشته می‌شوند؛ هر کدام را می‌توانید فعال/غیرفعال یا تغییر نام دهید.
4. **اجرا**: «اجرای الان» یا صبر برای زمان‌بندی. خروجی هر اجرا در تب «اجراها و خروجی» قابل مشاهده و دانلود است.

## ضبط با مرورگر (بدون نیاز به HAR)

یک بار روی سرور اجرا کنید: `sudo bash deploy/install-recorder.sh`. بعد در هر بخش «🎥 ضبط با مرورگر» را بزنید؛ سایت داخل پنل باز می‌شود، لاگین کنید، صفحه‌های بخش را باز کنید و روی یک مورد (پروفایل/شماره) کلیک کنید و «پایان و ذخیره» را بزنید. درخواست‌ها خودکار ساخته می‌شوند.

## بخش‌ها و داده‌ها

هر سایت چند **بخش** دارد (مثلاً پزشکان، مراکز درمانی، داروخانه‌ها). برای هر بخش جدا HAR بگیرید (فقط صفحه‌های همان بخش را باز کنید) و آپلود کنید. بعد از «گرفتن داده»، رکوردهای هر بخش جدا در پایگاه‌داده ذخیره می‌شوند، تکراری‌ها یکی می‌شوند و با دکمه «Excel» خروجی می‌گیرید. اگر آدرس درخواست `page=` دارد، در «تنظیمات بخش» تعداد صفحه را زیاد کنید تا همه صفحه‌ها گرفته شوند.

## محافظت‌های قراردادی

- هیچ درخواستی به دامنه‌ای خارج از «دامنه‌های مجاز» آن سایت ارسال نمی‌شود (هم هنگام آپلود HAR و هم هنگام اجرا بررسی می‌شود).
- بعد از تاریخ پایان قرارداد، اجرا خودکار متوقف می‌شود.
- فاصله بین درخواست‌ها قابل تنظیم است تا بار اضافه روی سرور طرف قرارداد نیاید.
- با `HARSCRAPER_UA_SUFFIX` می‌توانید یک شناسه (مثلاً `PartnerBot/1.0 (+contact@you.com)`) به User-Agent اضافه کنید تا طرف قرارداد ترافیک شما را تشخیص دهد.

## نکات

- **HAR حاوی کوکی و توکن نشست شماست.** پوشه `data/` را امن نگه دارید و پنل را بدون رمز قوی و HTTPS (مثلاً پشت Nginx) در اینترنت باز نکنید.
- نشست‌ها منقضی می‌شوند. اگر اجراها خطای 401/403 دادند، HAR تازه بگیرید و دوباره آپلود کنید.
- اگر طرف قرارداد API رسمی یا کلید API به شما می‌دهد، استفاده از آن پایدارتر از بازپخش HAR است.

## تنظیمات (متغیرهای محیطی)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `HARSCRAPER_USER` / `HARSCRAPER_PASS` | `admin` / `change-me` | ورود به پنل |
| `HARSCRAPER_DATA` | `./data` | محل پایگاه‌داده و خروجی‌ها |
| `HARSCRAPER_TIMEOUT` | `30` | زمان انتظار هر درخواست (ثانیه) |
| `HARSCRAPER_UA_SUFFIX` | خالی | پسوند User-Agent |

## ساختار

```
app/
  main.py      API، پنل و زمان‌بند
  har.py       خواندن HAR و استخراج درخواست‌ها
  scraper.py   بازپخش درخواست‌ها و ذخیره JSON
  db.py        SQLite
  static/index.html   پنل فارسی
data/output/site_<id>/run_<id>_<time>.json   خروجی‌ها
```
